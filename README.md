# 虎牙监控 iOS

一个面向个人使用的 iPhone 虎牙直播监控 App。目标是关注主播、查看弹幕、收听直播声音，并在主播开播时收到 iPhone 通知。

> 当前为第一阶段工程骨架：iOS 原生界面、关注主播本地保存、通知权限管理和本机测试通知已实现。虎牙实时弹幕、真实直播状态、直播音频和云端 APNs 开播推送尚未接入，界面会明确显示“数据源未接入”，不会伪造直播数据。

## 打开项目

使用 Mac 上的 Xcode 打开 `HuyaMonitor.xcodeproj`，选择 iPhone 模拟器后运行。项目最低支持 iOS 17。

## 当前已完成

- 监控、关注主播、设置三个页面。
- 可输入虎牙房间号或直播间链接添加关注主播。
- 关注列表保存在 iPhone 本地。
- 可为每个主播保存“开播提醒”偏好。
- 可申请 iOS 通知权限，并安排一条 5 秒后触发的本机测试通知。
- 不包含电脑软件中的置顶、隐藏和音量按钮。

## 尚未完成（需要后续数据接入）

- 虎牙主播在线/开播状态检测。
- 虎牙实时弹幕 WebSocket 接入。
- 直播音频流和后台播放。
- 云端监控服务、设备令牌注册和 APNs 远程推送。

## 重要说明

虎牙公开的旧弹幕 API 文档明确标注“本文档不再更新”，并指向虎牙小程序文档。它展示了历史 WebSocket 消息格式，但不能据此保证独立 iOS 客户端目前仍可稳定使用。正式接入前需要确认可用且获准使用的数据来源。项目不会把未经确认的私有接口或账号凭据写进客户端。

要实现 App 关闭后仍能收到主播开播提醒，需要云端服务检测开播状态，再通过 Apple Push Notification service (APNs) 发送远程通知。单纯在 iPhone 本地申请通知权限还不等于远程推送已接通。

## 项目结构

- `HuyaMonitor/`：SwiftUI iOS 应用。
- `docs/TECHNICAL_PLAN.md`：后续接入架构和前置条件。
- `.github/workflows/ios-build.yml`：GitHub Actions 模拟器构建检查。

## 隐私与密钥

不要把 Apple APNs 私钥、虎牙应用密钥、密码或个人访问令牌提交到 GitHub。正式后端配置应使用部署平台的 Secrets。
